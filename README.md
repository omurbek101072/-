# «Тазалык» муниципалдык ишканасынын порталы

Айыл өкмөтүнүн таза суу, таштанды, жайыт жана атайын техника кызматтары үчүн сайт (React + Vite + Tailwind).

## Иштетүү

Компьютерде [Node.js](https://nodejs.org) (20 же андан жогору) орнотулган болушу керек.

```bash
npm install
npm run dev
```

Андан кийин браузерден `http://localhost:3000` ачыңыз.

Интернетке жайгаштыруу үчүн: `npm run build` — даяр сайт `dist/` папкасында пайда болот.

## Админ

- Кирүү: сайттын эң ылдыйындагы «Кызматтык кирүү» же `Ctrl+Shift+A`.
- Баштапкы сырсөз: `1234`. **Биринчи киргенде дароо алмаштырыңыз:**
  Башкаруу панели → «Аталыштар & Мазмун» → «6. Админ PIN-код».
- 5 жолу туура эмес терилсе, кирүү 1 мүнөткө бөгөттөлөт.

## Документтер

Отчеттор бөлүмүндөгү PDF файлдарды `public/docs/` папкасына салыңыз (аттары `public/docs/README.md` ичинде).

## Маанилүү чектөөлөр

Азыр сайттын сервери жана маалымат базасы жок — бардык маалымат ар бир колдонуучунун өз браузеринде сакталат. Ошондуктан:

- тургундардын арыздары жана заказдары админге **башка компьютерден көрүнбөйт**;
- онлайн төлөм **демо режимде** — банкка туташкан эмес, чыныгы акча которулбайт;
- админ коргоосу браузерде гана иштейт, ал толук коопсуздук эмес.

Чыныгы колдонууга чыгаруу үчүн сервер/маалымат базасы (мисалы, Supabase же Firebase) жана төлөм системасы (MBank, Optima ж.б.) менен келишим керек.
