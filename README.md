# «Тазалык» муниципалдык ишканасынын порталы

Айыл өкмөтүнүн таза суу, таштанды, жайыт жана атайын техника кызматтары үчүн сайт.
React + Vite + Tailwind, маалымат базасы — [Supabase](https://supabase.com).

## 1. Supabase'ти даярдоо (бир жолу)

1. **Базаны түзүү.** Supabase → **SQL Editor** → **New query**. `supabase/schema.sql` файлын толугу менен көчүрүп салып, **Run** басыңыз.
2. **Админ башкаруу.** Жаңы query'ге `supabase/002_admin_management.sql` салып **Run**.
3. **Мазмун жана файлдар.** Жаңы query'ге `supabase/003_content.sql` салып **Run** (жаңылыктар, отчеттор, сүрөттөр үчүн).
4. **Кызматтар (жаңыртуу).** Мурунтан иштеп жаткан базада `supabase/004_services.sql` иштетиңиз — септик/водовоз алынып, суу түтүгү жана суу кампасын оңдоо кызматтары кошулат. Жаңы базада керек эмес (seed.sql'де бар).
5. **Пикирлер.** Жаңы query'ге `supabase/005_reviews.sql` салып **Run** (кардарлардын пикирлери үчүн).
6. **Жеке кабинет.** Жаңы query'ге `supabase/007_cabinet.sql` салып **Run** («Менин эсебим» бети үчүн).
7. **Операторлор жана журнал.** Жаңы query'ге `supabase/008_roles.sql` салып **Run**. Мындан кийин «Админдер» бөлүмүнөн кызматкерди **Оператор** ролу менен кошсо болот: ал абоненттерди, водомер көрсөткүчүн, кассадагы төлөмдү киргизет жана «Айлык эсептөө» жүргүзөт, бирок сайттын тексттерин, тарифтерди жана админдерди өзгөртө албайт. Ким эмнени өзгөрткөнү «Өзгөртүүлөр журналында» (админге гана көрүнөт).
7. **Баштапкы маалымат.** Жаңы query'ге `supabase/seed.sql` салып **Run** (сайттын тексттери, тарифтер, техника, жайыттар).
   Сыноо үчүн демо абоненттер керек болсо — `supabase/demo_subscribers.sql` (кийин өчүрсөңүз болот).
8. **Биринчи админ.** **Authentication → Users → Add user → Create new user**: email жана сырсөз жазып, **Auto Confirm User** белгилеңиз.
9. **Аны админ кылуу.** SQL Editor'до (email'ди өзүңүздүкүнө алмаштырыңыз):
   ```sql
   insert into public.admins (email) values ('сиздин@email.com');
   ```

Мындан аркы админдер SQL'сиз эле кошулат: **Башкаруу панели → Админдер** бөлүмүнө email кошосуз, ал адам сайттагы
**Кызматтык кирүү → Катталуу** аркылуу ошол email менен катталып, почтасына келген катты ырастап кирет.
Сырсөздү унутса — **Сырсөздү унуттум** (сайт интернетте турганда иштейт).

**Сайтты түз өзгөртүү.** Админ киргенде сайттын ар бир бөлүмүндө сары **«Өзгөртүү»** баскычтары жана тексттердин
жанында сары ✎ белгиси чыгат (жогорудагы **«Сайтты түз өзгөртүү»** баскычы менен өчүрүп-күйгүзүлөт):
жаңылыктар, документтер (PDF), бюджет, жайыт отчету, таштанды графиги, техника (кошуу/өзгөртүү/өчүрүү),
сүрөттөр жана бөлүмдөрдөгү тексттер. Ушулардын баары **Башкаруу панели → Жаңылыктар, отчеттор, сүрөттөр**
бөлүмүндө да бар. Сүрөттөр жүктөлгөндө автоматтык түрдө кичирейтилет.

> Supabase'те **Authentication → Sign In / Providers → Confirm email** күйүк турушу керек (баштапкы абалы ушундай).
> Ал болбосо бирөө админдин email'и менен катталып алышы мүмкүн эле — база ырасталбаган email'ге админ укугун бербейт.
> Сайт интернетке чыккандан кийин **Authentication → URL Configuration → Site URL** талаасына сайттын дарегин жазыңыз,
> ошондо почтадагы шилтемелер сайтка кайтат.

## 2. Иштетүү

[Node.js](https://nodejs.org) 20+ керек.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # даяр сайт dist/ папкасында
```

Supabase дареги жана ачык ачкычы `src/lib/supabase.ts` ичинде жазылган. Башка долбоорго которуу үчүн `.env` файлына `VITE_SUPABASE_URL` жана `VITE_SUPABASE_ANON_KEY` жазыңыз (`.env.example` караңыз).

## 3. Интернетке чыгаруу (акысыз)

[Vercel](https://vercel.com) же [Netlify](https://netlify.com) → GitHub репозиторийин тандаңыз → Build command: `npm run build`, Output: `dist`. Даяр.

## Ким эмне көрөт

| | Эл | Админ |
|---|---|---|
| Сайттын тексттери, тарифтер, техника | ✔ | ✔ + өзгөртөт |
| Арыз / заказ / водомер көрсөткүчү жөнөтүү | ✔ | ✔ |
| Арыздын абалы (номери боюнча) | ✔ (телефон, атысыз) | ✔ |
| Эсептин карызы (номери боюнча) | ✔ (аты жашырылган) | ✔ толук |
| Абоненттер, арыздар, заказдар тизмеси | ✘ | ✔ |
| Касса аркылуу төлөм киргизүү | ✘ | ✔ |

Эрежелер базанын өзүндө (Row Level Security) — сайттын кодун өзгөрткөн адам да аларды айланып өтө албайт.

## Онлайн төлөм

Азыр **демо режим**: тургун квитанцияны көрөт, бирок төлөм базага жазылбайт (жалган төлөм менен карыз жабылып калбашы үчүн).
Чыныгы төлөмдү админ **«Төлөм кабыл алуу (Касса)»** бөлүмүнө киргизет.
Банк же төлөм системасы менен келишим түзүлгөндө, онлайн төлөмдү туташтырып, `src/components/OnlinePaymentHub.tsx` ичиндеги `PAYMENTS_DEMO_MODE` өчүрүлөт.
